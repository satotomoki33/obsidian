## canバスの占有率を見る方法
1. ラテパン上コンテナの外で実行
  ```bash
  sudo modprobe vcan
  for octet in 16 17; do
    for bus in 1 2; do
      name="etf${octet}b${bus}"
      sudo ip link add dev "$name" type vcan 2>/dev/null || true
      sudo ip link set dev "$name" up
    done
  done
  ```
2. ノードを起動
3. コンテナ内で実行
  ```bash
  canbusload \
    etf16b1@1000000,8000000 \
    etf16b2@1000000,8000000 \
    etf17b1@1000000,8000000 \
    etf17b2@1000000,8000000
  ```

ロボますに一回駆動電源が入って情報が入らないと、診断は有効にならない
