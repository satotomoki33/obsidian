## 渡航中のルール・注意

### ホテル・会場外

- **必ず2人以上で行動する**。
- グループ内に連絡が取れる人を1人以上入れる。
- 行き先をLINEグループへ報告する。
- 荷物を無人状態で放置しない。

### 大会・グッズ

- 機構交換・機構譲渡はしない。もらうのは可。
- Test Run / 大会当日は **スポンサーロゴ入り作業着を着用しない**。
- **国旗を掲揚しない**。
- 運営から受け取るIDは大会期間中なくさない。帰国後にコピーを大学へ提出する必要がある。
- 毎朝、起床確認にリアクションする。

### 通信

- **QESにWi-Fiはない**。
- 選手ピット分はポケットWi-Fiを借りる想定。
- オブザーバーはeSIMを用意する。
- 競技用途の通信品質は主催者保証なし。

### 天候

- しおりでは香港は雨模様の想定。**傘を持っていく**。

## 競技運用で特に重要なこと

> ここは主に既存の [[ABU-Robocon-2026-香港参加ガイド]]（Participation Guidelines由来）の要点。実際の移動時刻は旅のしおりを優先する。

### Robot Check

- 8/22のRobot Checkは **先着順**。
- 1セッション **15分**。遅刻しても追加時間なし。
- ロボットが完全に組み上がってから代表者1名がRegistration Deskへ並ぶ。
- 未完成と判断された場合は列の最後に並び直し。
- 持参: 全ロボット、バッテリー、コントローラー、関連機器。
- 1st Robot Check: **8/22 09:15–11:15**。
- 2nd Robot Check: **8/22 12:45–14:45**。1st不合格箇所向け。
- Final Robot Check: **8/23 09:00–10:36**。
- 検査後、検査済みの設計・機能・部品を **Contest Committeeの事前承認・再検査なしで変更しない**。

### Test Run

- Queue Card順。
- 1枠15分で、フィールドへの移動・退出も含む。
- Session 1: **8/22 09:30–11:30**。
- Session 2: **8/22 13:00–15:00**。
- Session 2の各枠最後5分内で審判付き3分Test Run。
- 準備できていなくても予定どおり進行するため、Preparation Zoneへ早めに移動する。

### Practice Field

- 8/22 08:30–18:30、8/23 08:00–16:00。
- 1回6分。
- 1日最大5枠。
- 同時に保持できる予約は1枠。
- 搬入・搬出も6分に含む。

### Seeding

- 8/22 **15:35–17:45**。
- 相手なし、各チーム1回、Red Fieldで実施。
- セットアップ + KFS配置 1分、評価3分、1チーム割当8分（移動時間込み）。

### Pit / 電源 / 空圧

- Pitは **3m × 3m**。
- 日本Pitは **No.9**。
- 電源は1チーム **220V 1口**。
- **追加のextension socket接続禁止**。
- 自前コンプレッサーは会場内使用禁止。
- 大会側コンプレッサーは外径6mm空圧チューブ対応。チューブ・継手は持参。

### 安全

- Contest Fieldではつま先まで覆われた靴。
- ロボット動作時、Team Memberは **ヘルメット + 保護メガネ**必須。
- レーザーは相手・観客に光が届かないよう角度管理。

### 8/22終了時〜梱包

- 8/22夜は **ロボット・ロボット部品をQESから持ち出さない**。
- バッテリーは持ち出し可。
- 自チームの最後の試合が終わったら原則すぐ梱包開始。
- 優勝チームは8/23に梱包せず、8/24のデモ後に梱包。
- **8/24 11:30までに梱包完了**。

## 最低限覚えておく広東語

| 日本語 | 英語 | 広東語 | 読み |
|---|---|---|---|
| こんにちは | Hello | 你好 | ネイホウ |
| ありがとう（サービス等） | Thank you | 唔該 | ムゴイ |
| ありがとう（贈り物等） | Thank you | 多謝 | ドーチェ |
| すみません（謝罪） | Sorry | 對唔住 | デイムジュー |
| MTRの駅はどこ？ | Where is the MTR station? | 地鐵站喺邊度？ | デイティッザーム・ハイ・ビンドウ？ |
| お会計をお願いします | Bill, please | 唔該買單 | ムゴイ・マイダーン |
| Octopus Cardで払います | I'll pay by Octopus card | 嘟八達通 | ドゥッ・バッダートン |

## 病気・けが

### 命に関わる緊急時

- **999**（警察・消防・救急共通）。
- 英語・広東語対応。
- 原則、最寄りの公立病院救急外来へ搬送。搬送先の指定はできない。
- 救急車: `Ambulance, please.`
- 警察: `Police, please.`
- 消防: `Fire, please.`

### 非緊急時

- 自力で動ける場合は私立病院または日本人向けクリニックを調べ、電話予約して向かう。
- 公立病院は非居住者の費用が高く、しおり記載目安は救急外来 HK$2,100、一般外来 HK$500。
- 私立は高額だが、キャッシュレス保険に対応している施設が多い。

### AIGキャッシュレス診療

1. 受診前にAIGへ連絡し、キャッシュレス可否を確認。
2. 支払い保証書（Guarantee of Payment）を病院へ手配してもらう。
3. パスポートと保険証券（クレカ付帯ならクレジットカード本体）を持参。
4. 条件を満たせば窓口支払い不要。

AIGアシスタンスセンター: **+81 3-6371-0717**

### 立替払いになった場合

帰国後の請求のため、必ず受け取る:

- **正規の領収書（Original Receipt）**
- **診断書（Medical Certificate）**

日本の海外療養費制度を使う可能性がある場合は、海外療養費申請用紙への医師記入・署名も依頼する。

## 寝坊した場合

### 香港滞在中にQESへ遅れた場合

**バス（最もシンプル）**

Regal Riverside Hotel → ほぼ目の前の `Regal Riverside Hotel (ST517)` → **182 中環（Central / Macao Ferry）行き** → Cross Harbour Tunnel → Elizabeth House → 徒歩約10分 → QES。

- 乗換0回
- 料金目安 HK$20.8

**MTR**

Regal Riverside Hotel → Sha Tin Wai → Tuen Ma Line → Tai Wai → East Rail Line → Exhibition Centre → 徒歩約15分 → QES。

### 8/20出国日に寝坊した場合

- **11:30より前**: 起床連絡 → 最速準備 → I棟で航空券・スーツケース回収 → 事務局棟前へ。
- **11:30より後**: 起床連絡 → 最速準備 → I棟で航空券・スーツケース回収 → 自力で空港へ。
- 12:45より前の回収なら出発2時間前に空港着できる可能性あり。
- 13:45より前なら出発1時間前に着ける可能性あり。
- 14:00より前なら出発30分前に着ける可能性はあるがかなり厳しい。
- **14:00より後**: 基本的に予定便には間に合わない。起床連絡・荷物回収後、自力で香港行き航空券を手配。しおりでは単独行動回避のため8/21以降の便を指定。
