## 08:30–18:30　Practice Field

B/F に half-sized Practice Field が設置される．
赤ゾーンっぽい？（Seeding Evaliationと同じ）

### 予約

Practice Field Registration Desk で予約する．

- 列へ並べるのは各チーム 1 名
- 同時に保持できる予約は 1 枠
- 1 日最大 5 枠
- 1 枠 6 分
- 搬入出時間も 6 分に含む
- 開始時刻に Ready でなくても 1 枠消費する

### 運用方針

1日の枠が決まっているので，「枠が空いているから使う」ではなく，目的を決めて予約する．

例：
- ロボット組立後の
- Test Run で発覚した問題の再現
- パラメータ微調整
- 修正後の確認
- Seeding 前の最終確認

## Robot Check 受付

Robot Check は先着順．
ロボットの組立が完了したら，チームから 1 名を Registration Desk の列へ送る．
その後，現地スタッフが Pit まで来て，ロボットが完全に組み上がっていることを確認する．
確認後，queue card が発行される．
ロボットが Ready でないと判断された場合は，列の最後から並び直す．

### queue card

queue card の順番が Test Run の実施順になる．

したがって，

**開梱完了 → Robot Check 受付 → Robot Check → Test Run**

は一連の流れとして考える．

### Robot Check 後

Robot Check を通過した場合，または 15 分の確認時間が終了した場合，そのまま 3/F の Contest Field へ移動して Test Run へ進む．

安全上の問題がある場合は，問題が解消されるまで Test Run を停止される可能性がある．

### 1st Robot Check を通過できなかった場合

12:45–14:45 の 2nd Robot Check で再確認を受ける．

Seeding Evaluation へ参加するためには Robot Check を通過している必要がある．

### Robot Check 通過後の仕様変更

Robot Check 通過後，確認済みの部品・設計・機能を変更する場合は，Contest Committee の事前承認と再チェックが必要．
無断変更は失格につながる．

## 15:35–17:45　Seeding Evaluation

場所：3/F Contest Field

8:10 の Seeding Sequence Draw で決まった順に実施する．

Robot Check を通過しているチームのみ参加できる．

### 位置づけ

Seeding Evaluation は練習ではなく，翌日の Preliminary Round のグループ分けに使用されるイベント．
NHKのビデオ審査と同じような感じ．

本番と同じ，

- Setup
- Field elements
- Referee judgement

で実施される．

### 実施条件

各チーム 1 回のみ．
使用フィールド：
- Red Field

1 チーム 8 分枠．
8 分には B/F から 3/F Contest Field への移動時間も含まれる．
フィールドへ到着するとすぐに進行が始まる．

### 実施内容

1. Setup・KFS 配置：1 分
2. Seeding Evaluation：3 分
3. 残時間があれば Contest Field 全体を使用して練習可能
4. 8 分終了時には速やかに撤収

次チームは Preparation Zone で待機する．

### 方針

ここでは新しいことを試さない．
その時点で最も早くKFMできる戦略でロボットを動かす．

目標：**できる限り高い Seeding 順位を確保する**
実質1st と 2ndの2枠が確定シード枠みたいなもん

### 評価順位

優先順位は以下．

1. Kung Fu Master 達成
2. Kung Fu Master 達成時間
3. 3 分間の総得点
4. Tic-Tac-Toe 得点
5. Arena 上の KFS 得点
6. Martial Club 得点
7. R1 が最初に Martial Club を出るまでの時間
8. 最終的には Contest Committee 判断

全チーム終了後，22 日夜に Seeding 順位と Preliminary Round のグループが発表される．

### 空圧

運営提供コンプレッサー：

- B/F Robot Check 付近 × 1
- 3/F Preparation Zone × 1

接続：
- 外径 6 mm pneumatic tubing

チーム側でチューブと継手を準備する．
自前コンプレッサーは会場内で使用禁止．
次の試合へ出場するチームが優先される．

- Test Run
- Match

- Helmet
- Safety goggles
を着用する．

ピットではつけなくてもいいっぽい．
