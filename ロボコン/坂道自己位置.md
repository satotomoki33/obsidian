> [!NOTE]- >  次に怪しい：IMUが重力を加速度として入れている
> 
> geolocはIMUのyaw角速度だけでなく、x・y方向の線形加速度もUKFに入れています。
> 
> IMUドライバから来た `sensor_data->accel` は、そのまま `linear_acceleration` として渡されています。
> 
> ここで、`accel` が重力除去済みかどうかが非常に重要です。
> 
> Rampは水平長1.5 m、高さ0.4 mなので、傾斜は約14.9°です。
> 
> 重力が除去されていなければ、坂上で静止しているだけでも機体の坂方向に、
> 
> ```
> 9.81 × sin(14.9°) ≒ 2.52 m/s²
> ```
> 
> の加速度が観測されます。
> 
> R1は横向きで登るため、おそらく機体座標の`y`方向に大きな値が出ます。UKFがこれを実際の加速として積分すると、数秒で数m規模の誤差になることもあります。
> 
> 坂で静止した状態で以下を確認してください。
> 
> ```
> ros2 topic list | grep -E 'imu|gyro'
> ```
> 
> 見つかったIMUトピックに対して、
> 
> ```
> ros2 topic echo <IMUトピック名>
> ```
> 
> を実行し、静止中の、
> 
> ```
> linear_acceleration.x
> linear_acceleration.y
> ```
> 
> を見ます。
> 
> ### 正常な重力除去済み加速度
> 
> ```
> x ≈ 0
> y ≈ 0
> z ≈ 0
> ```
> 
> ### 重力を含んでいる可能性が高い値
> 
> ```
> xまたはy ≈ ±2.5 m/s²
> z ≈ 9.4 m/s²前後
> ```
> 
> この場合は、geolocへ入れる前に重力を除去するか、当面はIMUからyaw rateだけを使用する必要があります。
>
