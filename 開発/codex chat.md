# Codexはすばらしい！
ローカルのファイルいじるのすばらしい
でもやっぱりCLIは読みづらいしブラウザでのチャットみたいにチャット履歴とか前のメッセージとか編集できたほうがもっと使いやすいのでは

webブラウザで動くCodex
history付き
前回の会話の編集(流石にその会話でなんか色々コマンド打ってたりしてたら戻す処理面倒だろうからコマンド打ってないときだけ編集できる)
codexって写真対応してたっけ？してるんやったらコピペで写真も送れるようにしたい

1. Codex CLI のJSON/イベント出力に合わせたコマンド実行ログの精密パース
2. 危険コマンド検出と承認UI
3. ファイル変更検知と編集ロックの強化
4. 添付画像のサムネイル表示と削除
5. 会話タイトルの自動生成
6. Codexプロセスの停止ボタン
7. ワークスペース選択UIのディレクトリブラウザ化
8. 後付けサンドボックス実行層

チャット入力欄の横に+マークみたいなやつつけてファイル、フォルダの参照ができるようにする
@って打ったら参照フォルダ、ファイルの予測が出てくるUI
/ってうったらAgentのモードとか書き込みありなし、聞くだけ、とかなんかいろいろモードを追加できるようにしたい。それもUI予測ができる
履歴残すモードみたいなのがあってそれをONにしておくとobsidianのそれ用のフォルダの中にどういう会話をしたのか会話内容をいい感じに読みやすくまとめてくれる

普段codexのアクセスはフルアクセスにしてるからワークスペースのみって制限も外していい
コマンド打つのめんどくさいのでアプリ化
アプリを押したらサーバーが開いてブラウザも開く感じで
