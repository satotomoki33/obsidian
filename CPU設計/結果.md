## 課題4.0
うん、**これで合ってる！**  
課題4.1の波形確認としてはかなり良い感じ。

見えてる値も期待通り。

```text
0ns    a=4  b=3  q=7  VF=0
100ns  a=4  b=4  q=8  VF=1
200ns  a=c  b=c  q=8  VF=0
300ns  a=c  b=b  q=7  VF=1
```

意味としては、

```text
4 + 3 = 7        → 符号付きでも問題なしなので VF=0
4 + 4 = 8        → 4bit符号付きだと +8 は表せず -8 扱いなので VF=1
c + c = 8        → c は -4、-4 + -4 = -8 なので表現可能、VF=0
c + b = 7        → c は -4、b は -5、合計 -9 は表せないので VF=1
```

4bit符号付き整数はだいたい、

```text
0111 =  7
1000 = -8
1100 = -4
1011 = -5
```

って読む。

なので、レポートにはこんな感じで書ける。

> 各STEPごとに入力 a, b が変化し、それに応じて加算結果 q とオーバーフローフラグ VF が変化することを確認した。4+3では q=7, VF=0 となり正常に加算された。4+4では符号付き4bit表現の範囲を超えるため、q=8 となり VF=1 が出力された。-4+-4では q=8 となり、これは符号付き4bitで -8 を表すため VF=0 である。-4+-5では表現範囲を下回るため q=7 となり VF=1 が出力された。

## 課題4.4
うん、**合ってる！** これはちゃんと **4bitリングカウンタ**になってる。

波形が、

```text
X → 1 → 2 → 4 → 8 → 1 → 2 → 4 → 8 → ...
```

2進数で見ると、

```text
0001 → 0010 → 0100 → 1000 → 0001 → ...
```

つまり `1` が1ビットずつ左に移動して、最後にまた最初へ戻ってる。これがリングカウンタの動作。

最初の `X` は未初期化だから問題なし。`res=1` で `q=1` に戻って、その後 `res=0` で周期的に回ってるので正しい。

レポートにはこう書ける。

> シミュレーションの結果、リセット中は出力 `q` が `0001` となり、リセット解除後はクロックの立ち上がりごとに `0001 → 0010 → 0100 → 1000 → 0001` と周期的に変化した。したがって、4bitリングカウンタとして正しく動作することを確認した。
