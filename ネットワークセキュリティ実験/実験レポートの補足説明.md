### ターミナル・コマンドラインでの注意事項

- 攻撃者検知実験のスクリプトを detect.sh とする時、  
    　**$ sudo ./detect.sh &    **# ← 注意: この方法は（特に Unix 初心者～中級者には）おすすめしません****  
    と "**&**" を付けて実行すると、root 権限で detect.sh がバックグラウンド実行されるため、一般ユーザ権限で制御ができなくなります。  
    対処方法はありますが、一般ユーザ権限で動作するスクリプトを作るほうが安全です。  
    Apache のログ参照時と、iptables 実行時など root 権限が必要な箇所でのみ sudo を使うようにしましょう。
- 上記とも関連しますが、攻撃者検知実験スクリプトを  
    　**$ ./detect.sh**  
    として実行した際は、Ctrl-C でスクリプトを終了させてください。  
    Ctrl-Z で  
    　**[1]+  stopped ./detect.sh**  
    などと表示されますが、これは一時停止を意味し、ジョブ（プロセス）は終了せずに、ある時点で停止したままになります。  
    Ctrl-Z を押してしまった際は、慌てずに、  
    　**$ fg  
    **あるいは、スクリプトを root 権限で実行してしまった場合は、  
    　**$ sudo fg**  
    と入力してください。一時停止中の detect.sh が継続動作します。  
    （**fg** は「フォアグラウンドで一番最後に停止したジョブの継続動作させる」の意味。「fg bg jobs」で検索すると、詳しい使い方は調べられますが、慣れないうちは、Ctrl-Z や "&" を使わないようにしましょう。detect.sh の多重起動を防げます。）
- 攻撃者検知実験では、2枚のターミナルから Webサーバへ接続する方法を強くおすすめします。**1つは「detect.sh を実行するターミナル」として、もう1つは「top を起動するターミナル」として、それぞれ実行しましょう**。
- ターミナルで **Ctrl-S を押してしまうと**、端末のフロー制御を停止し、標準入出力が抑制されるため、キーボード・コマンドの入出力が止まって見えますが、**慌てず Ctrl-Q を入力してください**。フロー制御が再開され、標準入出力が停止時点から再開されます。

### 基礎実験・攻撃者検知実験共通

- **攻撃用サーバの sample.cnf で書き換えて良い項目は、TIMER_AFTER_URL_SLEEP=○○○ の ○○○ 部分のみです**。それ以外を変更すると、他の人のサーバを攻撃してしまうなど、不具合が生じます。
- **CSV データ・スクリプトは WinSCP などで適宜バックアップするようにしてください**。
- Excel を使って、CSVデータから、折れ線グラフを作成してください。
- top のログの取り方は、次のとおりです:  
    　**$ top -b -d 1 -n 150 > top_basic_100.log**   
    （攻撃用サーバの sample.cnf が TIMER_AFTER_URL_SLEEP=100 の場合）
- 攻撃用サーバの sample.cnf のパラメータを変えるたびに、**「メモリキャッシュのクリア」と「Apache の再起動」を忘れずに実行してください**。

### 攻撃者検知実験

- 攻撃者検知実験を一度だけ行っても、効果を実感しにくい場合があります。  
    その場合は、攻撃者検知スクリプトを動作させたまま、数分後に、もう一度 curl-loader で口撃してみてください。  
    おそらく、TIMER_AFTER_URL_SLEEP のパラメータによっては、CPU・メモリの使用状況や Apache のログが増えないことを確認できると思います。
- コマンドの実行結果の終了ステータスをひっくり返す（真→偽、偽→真）にするには、「!  コマンド」を使ってください。
- 無限ループには、「**while true ...**」か「**while : ...**」を使ってください。  
    true も : （コロンコマンド）のどちらも「標準出力に何も出力せず、しかし、終了ステータスが 0（真）になることが保証されているコマンド」です。
- 攻撃者検知実験スクリプトの内部で一時的に使われるファイル（テンポラリファイル）は、スクリプト冒頭部でファイルの中身を空にしないと、おそらく誤動作します。  
    そこで、「**:  >  ファイル名**」あるいは「**ture  > ファイル名**」などと書いて、ファイルの内容を 0 バイトにしましょう。  
    （ただし、コマンドラインで実行しないようにしましょう。実験データなどをこの方法で初期化すると、中身が消えてしまいます。
- 攻撃者検知実験では、smaple.cnf のパラメータを変更するたびに、 **iptables に登録されたIPアドレスも初期化する必要があります**。  
    詳しくは、指導書の「4.6.4 Commands when initializing iptables」（補足資料の「2.6.4 iptables を初期化したいときのコマンド」）を参照のこと。
