# テンプレート集

## Daily note

```md
# YYYY-MM-DD

## Tasks

## Schedule

## Logs

## Notes
```

---

## Task

```md
- [ ] タスク名 📅 YYYY-MM-DD #task
  - project: [[プロジェクト名]]
  - memo:
```

---

## Schedule

```md
- HH:MM 予定名 #schedule
  - location:
  - memo:
```

時刻不明の場合:

```md
- 予定名 #schedule
  - time:
  - location:
  - memo:
```

---

## Log

```md
- 作業内容 #log
  - project: [[プロジェクト名]]
  - memo:
```

---

## Project overview

```md
# プロジェクト名
```
