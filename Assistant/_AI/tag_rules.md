# タグルール

タグは増やしすぎない。  
迷ったら基本タグだけ付ける。

## 基本タグ

- `#task` : タスク
- `#schedule` : 予定
- `#memo` : メモ
- `#log` : 作業ログ

## 分野タグ

- `#university` : 大学関連
- `#robocon` : ロボコン関連
- `#programming` : プログラミング
- `#report` : レポート
- `#git` : Git関連
- `#obsidian` : Obsidian関連

## 優先度タグ

- `#high` : 重要
- `#low` : 低優先度

## 注意

- 新しいタグを勝手に増やしすぎない
- 判断に迷った場合は `#memo` または `#task` のみでよい
- タスクには原則 `#task` を付ける
- 予定には原則 `#schedule` を付ける
- 作業ログには原則 `#log` を付ける
