# エミュ機改造

## 概要
Linux系携帯エミュレーターゲーム機をベースに、ゲーム・スクリプト実行・SSH開発・Androidブラウザを1台で実現するCyberdeckプロジェクト。

## コンセプト
- 普段はレトロゲーム機
- コントローラーだけでLinuxアクションを実行
- キーボード+外部画面でSSH開発
- Androidでブラウザ・GUIアプリ利用

## MVP
- [ ] エミュレーター動作
- [ ] Action Deck（コントローラーからスクリプト実行）
- [ ] SSH開発モード
- [ ] Androidブラウザモード

## 方針
1. 既製品を壊さずソフトウェアから開発
2. Linuxはゲーム・SSH・Action Deck担当
3. Androidはブラウザ担当
4. 重い処理はリモートPCへ
5. ゲーム機としての使いやすさを維持

## モード
- ゲームモード
- Action Deck
- SSH開発モード
- Androidブラウザモード

## 候補機種
第一候補: ANBERNIC RG353V
- Linux + Android
- HDMI出力
- USBキーボード対応
- Wi-Fi
