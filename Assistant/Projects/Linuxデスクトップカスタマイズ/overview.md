# Linuxデスクトップカスタマイズ

## 概要

Hyprland・Quickshellなどを使って、Linuxのデスクトップ全体をゲームUIのように作り込む「ricing」に興味がある。

きっかけは、Persona 3風のインターフェースを実装した **Persona-Quickshell**。単に壁紙や配色を変えるだけではなく、ランチャー、ステータスバー、OSD、電源メニュー、画面遷移などまで含めてデスクトップシェル全体をデザインするタイプのプロジェクトを試してみたい。

## やってみたいこと

- Hyprlandを使ったWaylandデスクトップ環境を触る
- Quickshell/QMLでUIを自作・改造する
- PersonaのようなゲームUI風のデスクトップを作る
- 既存のrice / dotfilesを導入して構成を学ぶ
- 気に入った構成をforkして自分用にカスタマイズする
- 将来的には開発用途の情報もUIへ統合する
  - CPU / RAMなどのシステム情報
  - VS Code / Obsidianなどのランチャー
  - GitHub関連情報
  - ROS 2のノード状態など

## メモ

Linuxの見た目を変えるだけではなく、デスクトップUIそのものをプログラミングできる点に特に興味がある。既存環境を壊さず試すなら、普段のGNOME等を残したままHyprlandを別セッションとして導入する方針が候補。
