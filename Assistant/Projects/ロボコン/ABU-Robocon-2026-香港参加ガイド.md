## まず最重要ポイント

- 大会本番は **2026-08-23（日）**、会場は **Queen Elizabeth Stadium（QES）**。
- 日本代表は **TUT / Toyohashi University of Technology（豊橋技術科学大学）**。
- QESには **Wi-Fiがない**。競技で通信を使う場合はチーム側でSIM等を含め通信手段を用意する。
- 香港の電源は **220V / 50Hz**。
- 8/22のRobot Checkは **先着順**。ロボット未完成だと列の最後に並び直し。
- Robot Checkは1回 **15分**。遅刻しても追加時間なし。
- Robot Check合格後に、検査済みの設計・機能・部品等を **無断変更すると失格**。変更する場合はContest Committeeの承認と再検査が必要。
- Test Runは **Queue Card順**。1枠15分で、フィールドへの移動・退出時間も含む。
- Practice Fieldは1回 **6分**、1日最大 **5枠**。同時に保持できる予約は1枠のみ。
- Pitは **3m × 3m**。日本チームのPitは **No.9**。
- Pitの電源は **1チームにつき220Vコンセント1口**。追加の延長コンセント接続は禁止。
- 自前コンプレッサーは **会場内で使用禁止**。大会側の2台を使用する。
- ロボット動作中、Team Memberは **ヘルメット＋保護メガネ＋つま先の覆われた靴**が必要。
- 8/22夜にQESから **ロボット・ロボット部品を持ち出すのは禁止**。ただしバッテリーは持ち出せる。
- 8/23朝に **Final Robot Check（09:00–10:36）**。
- 自チームの最後の試合が終わったら、原則すぐ再梱包開始。
- 8/24は **11:30までに梱包完了**。
- 8/25は **12:00までにチェックアウト**。
- 観客席では **国旗は禁止**。大学バナーは1枚のみ可。

# 11. Robot Check

## 基本

Test Run前に全チーム必須。

**先着順（first-come, first-served）**。

1セッション **15分**。遅刻しても延長なし。

## Queue Cardをもらうまで

1. ロボットを完全に組み立てる
2. チーム代表者1名がRegistration Deskに並ぶ
3. スタッフがPitへ来て、ロボット完成状態を確認
4. 完成していればQueue Card発行
5. 未完成の場合、列の最後に並び直し

## 検査に持っていくもの

- 全ロボット
- バッテリー
- コントローラー
- その他関連機器

## 検査後

Robot Check合格、または15分セッション終了後は、そのまま3/F Contest Fieldへ向かいTest Runへ進む。

## 非常に重要: 検査後の変更

Robot Check合格後に、検査済みの項目・設計・機能を **Contest Committeeの事前承認と再検査なしで変更すると失格**。

現地で修理・改造が必要になった場合は、先にスタッフへ確認する。

## Robot Check日程

### 1st Robot Check

- 8/22 09:15–11:15
- ここで通れば2nd Robot Check免除

### 2nd Robot Check

- 8/22 12:45–14:45
- 1stで通らなかったチーム向け

### Final Robot Check

- 8/23 09:00–10:36

確認内容:

- 重量
- 空気圧
- バッテリー電圧
- サイズ
- 安全性
- ルール適合

Final Robot Checkに通らない場合、競技参加を認められない可能性がある。

## Session 1

- 8/22 09:30–11:30
- 奇数Queue Card → Blue

- 遅刻・欠席による追加枠なし

## Session 2

- 8/22 13:00–15:00
- Session 1と左右を逆にする
  - 奇数 → Red
  - 偶数 → Blue
- 各枠の最後5分内で **審判付き3分Test Run**
- チームが準備できていなくても予定どおり進行
- 開始時刻にフィールドにいない場合、次のチームが入る
- 遅れたチームはPreparation Zoneで待ち、次の空き枠へ回される

# 14. Seeding Evaluation

8/22 **15:35–17:45**。

相手なしで各チーム1回のみ、**Red Field**で実施。

本番と同じ:

- セットアップ手順
- フィールド要素
- 審判判定

で行う。

## 1チームの流れ

- セットアップ + KFS配置: **1分**
- Seeding Evaluation: **3分**
- 1チームの割り当て: **8分**
  - B/Fから3/F Contest Fieldへの移動時間を含む

走行終了後、枠に残り時間があればContest Field全体を使って練習してよい。

## シード順位の優先基準

1. Kung Fu Master達成
2. Kung Fu Master達成時間が短い
3. 3分間の総得点
4. Tic-Tac-Toe得点
5. Arena上のKFS得点
6. Martial Club得点
7. R1が最初にMartial Clubから退出するまでの時間が短い
8. 最終的にContest Committeeが決定

# 15. 大会形式

## Round 1

16チームを6グループに分ける。

- Group A〜D: 各3チーム
- Group E〜F: 各2チーム

各チームはRound 1で **2試合**。

- Red Fieldで1試合
- Blue Fieldで1試合

## Round 2進出

Round 1から **8チーム**が進出。

- 各Group A〜Fの1位チーム: 6チーム
- 各グループ2位から成績上位: 2チーム

グループ1位6チーム、および2位候補の比較基準は概ね次の順。

1. 勝利数
2. Kung Fu Master達成回数
3. 勝利試合での総得点
4. Kung Fu Master達成時間
5. Tic-Tac-Toe得点
6. Arena KFS得点
7. Martial Club得点
8. R1のMartial Club退出時間
9. Contest Committee判断

Round 2〜4はノックアウト形式。

# 18. 安全規則

## 靴

Contest Fieldでは常に **つま先まで覆われた靴（スニーカー等）**。

## ロボット動作時

Practice / Test Run / Matchでロボットを動かす際、Team Memberは:

- ヘルメット
- 保護メガネ

が必須。

Pit Crewにも強く推奨。

保護具はチームで用意する。

## PETボトル空圧

PETボトルに圧縮空気を入れる場合、破裂防止措置が必要。十分な保護がないものは使用不可。

## レーザー

光が相手チーム・観客に届かないようビーム角度を管理する。

## 安全上問題があるロボット

Contest Committee / Refereeが危険と判断した場合、改造を要求されることがある。

- 全ロボット組立完了
- バッテリー
- コントローラー
- 必要機器
- 重量 / サイズ / 圧力 / 電圧を自分たちでも事前確認

## Robot Check後

- 検査済み部分を勝手に変更しない
- 修理・改造が必要ならContest Committeeへ確認
- Queue Cardの番号とSideを確認

## Test Run / Seeding前

- 移動時間込みで枠が消費されることを意識
- Preparation Zoneへ早めに移動
- 必要な工具・予備品を絞って持つ
- ヘルメット・保護メガネ着用

## 8/22終了時

- ロボット・部品はQESに残す
- 必要ならバッテリーのみ持ち帰る
- 貴重品を回収

## 8/23本番

- 09:00 Final Robot Check
- 自チームの試合終了後、次戦がなければ梱包へ移行
- 優勝した場合は8/23に梱包しない

- Friendship Exchange
- **11:30までに梱包完了**
