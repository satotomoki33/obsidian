# 大学院進学・研究室候補

## 興味の方向

大学院では、次のような知能ロボティクス・自律移動系の研究をしたい。

- 街中・歩道を走る配送ロボット、サービスロボット
- 自律移動ロボット
- SLAM / Localization / 自己位置推定
- LiDAR・Cameraなどを使った環境認識
- 経路計画・経路追従
- センサフュージョン
- 自動運転
- 実機を使った研究

特に、ロボコンで触れてきたROS 2、LiDAR、自己位置推定、経路生成・追従、制御などの経験とつながる研究がよさそう。

## 特に気になる研究室

### 筑波大学 知能ロボット研究室

現時点ではかなり本命寄り。

研究テーマに以下がある。

- 屋内・屋外の実環境での自律ナビゲーション
- 人間と共存する生活空間で働くロボット
- 未知環境の地図作成・自己位置推定
- SLAM
- LiDARによる地図生成
- オドメトリと外界センサのセンサフュージョン
- 経路計画

修士学生のテーマにも、歩道環境での自律走行、歩行者流を考慮したNavigation、3次元自己位置推定、走行可能領域地図生成、経路計画などがあり、街中の配送ロボットにつながりやすい。

- https://www.roboken.iit.tsukuba.ac.jp/
- https://www.roboken.iit.tsukuba.ac.jp/theme/
- https://www.roboken.iit.tsukuba.ac.jp/member/
